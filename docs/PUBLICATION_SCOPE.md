# Publication scope / Yayın kapsamı

## Public evidence

- Bilingual product and architecture documentation
- Anonymous workflow visuals
- A small, executable .NET 9 sample
- Selected DTO, endpoint and domain-rule examples
- Documented API, authentication and persistence decisions
- Verification notes and known limitations

## Private product assets

- Complete ERP/MRP source tree
- Full authentication and refresh-token implementation
- Complete EF Core model, migrations and seed catalog
- Customer databases, credentials and environment secrets
- Production designs, machine files and machine endpoints
- Proprietary planning, costing and manufacturing rules
- Operational Docker deployment configuration

## Review principle

The public material must be sufficient to evaluate code quality and technical judgment, but insufficient to deploy, resell or reconstruct the complete product. Screens use fabricated data and do not contain information belonging to a real company.

Public içerik kod kalitesini ve teknik kararları değerlendirmeye yetecek; tam ürünü çalıştırmaya, yeniden satmaya veya üretim entegrasyonlarını kopyalamaya yetmeyecek şekilde sınırlandırılmıştır. Görseller yalnızca kurgusal demo verisi içerir.

## Product focus / Ürün odağı

The product supports web, Windows desktop and Android client applications through a shared REST API and JWT identity model. The portfolio review path focuses on the web application, protected routes, PostgreSQL and Docker because web is the current delivery priority. Desktop and mobile clients are acknowledged without claiming feature parity.

Ürün; ortak REST API ve JWT kimlik modeli üzerinden web, Windows masaüstü ve Android istemcilerini destekler. Web güncel teslimat önceliği olduğu için portföy inceleme yolu tarayıcı uygulamasına, korunan rotalara, PostgreSQL'e ve Docker'a odaklanır. Masaüstü ve mobil istemciler, özellik eşitliği iddiası kurulmadan belirtilir.
